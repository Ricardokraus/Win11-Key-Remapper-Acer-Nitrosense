# 💬 Help and feedback

[← Back to the README](README.md)

Something doesn't work, you have an idea, or a question? Everything goes through
GitHub **Issues**: it's public, so the next person with the same problem finds
the answer too. The same links are in the app: settings window → *About*.

## First, a quick look

- The [**FAQ**](docs/FAQ.md) answers the most common questions: AutoHotkey,
  antivirus warnings, Task Manager, Win Lock, the settings file…
- The [**Issues tab**](https://github.com/Ricardokraus/Win11-Key-Remapper-Acer-Nitrosense/issues)
  may already have it: type a few words in the search box. If you find it, add a
  👍 or a comment with your details instead of opening a new one.

## Open an issue, step by step

1. Sign in to GitHub (a free account is enough).

2. Go to
   [**New issue**](https://github.com/Ricardokraus/Win11-Key-Remapper-Acer-Nitrosense/issues/new/choose)
   and pick the form that fits:

   | Form | Use it when |
   |---|---|
   | 🐞 [**Bug report**](https://github.com/Ricardokraus/Win11-Key-Remapper-Acer-Nitrosense/issues/new?template=bug_report.yml) | Something doesn't work as expected. |
   | 💡 [**Feature request**](https://github.com/Ricardokraus/Win11-Key-Remapper-Acer-Nitrosense/issues/new?template=feature_request.yml) | You have an idea or an improvement. |
   | 💻 [**Works on my laptop**](https://github.com/Ricardokraus/Win11-Key-Remapper-Acer-Nitrosense/issues/new?template=works_on_my_laptop.yml) | You tried it on your model, whether it worked or not. |
   | ❓ [**Question**](https://github.com/Ricardokraus/Win11-Key-Remapper-Acer-Nitrosense/issues/new?template=question.yml) | Anything else. |

3. Fill in the form. For a bug, the more precise the better: what you did, what
   you expected, what happened instead, and the app version (settings window →
   *About*).

4. Click **Create**. GitHub emails you when someone answers.

## Security problems

Please **don't** open a public issue: report it privately, as explained in
[SECURITY.md](SECURITY.md).
